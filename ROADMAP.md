# 🗺️ JAVASCRIPT MASTERY ROADMAP (50-DAY ACADEMY CURRICULUM)

Welcome to the structured syllabus roadmap of the JavaScript Mastery Workbook. This curriculum breaks down the 50 days into logical progressive learning phases.

---

## 🧭 Phase-by-Phase Roadmap Table

| 📅 Day Range | 🎯 Learning Phase | 🧬 Core Concepts Covered | 📌 Milestone Project |
| :--- | :--- | :--- | :--- |
| **Days 01 - 14** | **JavaScript Foundations** | Scopes (`let`/`const`), Memory models (Stack/Heap), Comparisons, Loops, Functions, Array manipulation, Math.random. | None (Foundations) |
| **Day 15** | **Milestone 1** | Dynamic switcher routing, validation handling. | **Simple Calculator** |
| **Days 16 - 29** | **Intermediate JS & Closures** | Precedence, Type coercions, Scope Chain lookup, Closures, Currying, Function composition, Scoping details. | **Theme Switcher** (Day 20)<br>**Interactive Quiz** (Day 25) |
| **Day 30** | **Milestone 2** | Metric indices checks, string conversions. | **BMI Calculator** |
| **Days 31 - 44** | **DOM & Advanced OOP** | `var` loop leaks, DOM Selection, CSS Styling controls, Object descriptors, Prototype chains, ES6 Classes and Inheritance. | **Todo List App** (Day 33)<br>**Expense Tracker** (Day 37)<br>**Weather Dashboard** (Day 40)<br>**Kanban Board** (Day 43) |
| **Day 45** | **Milestone 3** | State tracking, hot/cold guess logics. | **Number Guessing Game** |
| **Days 46 - 49** | **Asynchronous JS & Architecture** | Async-Await, Fetch API, ES6 modular simulation, Reactive Pub/Sub State stores, Custom Event Brokers. | **Profile Card Generator** (Day 48) |
| **Day 50** | **Milestone 4** | Aggregates calculation, Rank allocation. | **Student Marks Manager** |

---

## 🎛️ Milestone Applications Summary

* 💻 **Milestone 1 (Calculator):** Basic mathematical evaluations check.
* 🌈 **Milestone 2 (BMI Calculator):** Metric indices computations and categorizations.
* 🎯 **Milestone 3 (Number Guessing Game):** Random number hot/cold feedback loops.
* 🎓 **Milestone 4 (Marks Manager):** Score aggregation and grade rank allocation.
* 💼 **Landmark Widgets (5-11):** Standalone mini-apps (Kanban, Expense Tracker, Profile Generator, Quiz App, Todo, Theme Switcher, Weather Widget).
